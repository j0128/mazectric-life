# 生存遊戲 · Mazectric

瀏覽器裡的細胞自動機殖民地模擬。規則是 Mazectric **B3/S1234**（誕生剛好 3 鄰、存活 1–4 鄰）。活細胞就是人口；連通 ≥12 且有實心 2×2 才算聚落。東西向世界會繞接。目前版本 **v4.6**。

連饑 10 代後，搶不到糧的族可能內戰或立刻散族（被吃時技能聯集繼承）。每鎮特質、工藝、遺芳各一項。不同地方同時成鎮會隨機抽第一／第二／第三文明；只有連通的同一團共用號。山邊／水邊／林邊鎮可學會越山、涉水、林棲；岸鎮遠航、貼冰冰行、已越山可山居（只有附近生效）。已有銅的鎮：大局至少 1000 代才可能升青銅，至少 2000 代才可能升鐵（同一工藝槽）。放大可見鎮名與光環；點格看詳情。高地有礦點；商隊可能過路留糧。約萬代岸線大退或湖沼擴張。點側欄文明名稱可在地圖上突出該族。火山沒爆發會改期變兇；中冰期減糧、散點較易死。

## 直接玩

開 https://j0128.github.io/mazectric-life/ 即可玩（每人自己一局，不是多人同圖）。要放到 Google 協作平台：插入 → 嵌入，貼同一個網址。

本機可雙擊 `視窗版.bat`（獨立視窗，切走仍會演化），或用瀏覽器開 `index.html`。

## 畫風

v4.6 改成類似《八方旅人》的 HD-2D 風格：像素地圖加上泛光、上下移軸模糊、暈影與黃昏色調；山壁有南向岩面、樹有冠與落影、活細胞有投影，鎮有暖色光暈。介面採深靛色底配金線，標題與數字用 Cinzel，中文用思源宋體（Google Fonts，離線時退回系統襯線字）。

## 種子、存檔與測試

- 全部亂數走可設種子的 `js/rng.js`。同一個種子＋同一串操作，一定得到同一局；狀態列會顯示本局種子。
- **存檔**＝種子＋操作紀錄（很小）。「存檔」下載 JSON，「讀檔」會重播到存檔時的代數。瀏覽器也會每 100 代與離開頁面時自動存，下次開啟選尺寸畫面會出現「繼續上次那局」。
- 引擎不依賴 DOM，可在 Node 跑：`node test/determinism.js`（檢查同種子重現、存檔重播與原局一致；`STEPS=N` 可改步數）。

## 開什麼、不開什麼

這個 repo **只含這款遊戲**（`index.html`、`js/`、`css/`）。沒有舊版備份夾，也沒有同一個工作區裡的其他專案。
